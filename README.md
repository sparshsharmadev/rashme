# RASHMÉ Website

A multi-page website for RASHMÉ, an Ayurvedic hair-care brand.

**Live site:** [rashme.in](https://www.rashme.in)

The site includes product and ingredient information, brand and story pages, rituals, and customer information pages. The repository contains the static site source and Vercel configuration.

## Run locally

This repository does not require an npm build step. From the repository root, start any static file server, for example:

```bash
python -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Structure

- `index.html` — home page
- `products.html`, `ingredients.html` — product and ingredient information
- `brand.html`, `story.html`, `rituals.html` — brand content
- `contact.html`, `privacy.html`, `terms.html`, `refund.html` — contact and policy pages
- `css/`, `js/` — stylesheets and site scripts

## Tech

HTML · CSS · JavaScript · Vercel
